# 硬件与设备调研

个人用的**选购、对比、库存**笔记库。按设备类型分目录，各目录内用 Markdown 表格追加调研行即可。

## 目录

| 分类 | 说明 |
|------|------|
| [diy-台式机](./diy-台式机/README.md) | DIY 装机：CPU、主板、显卡、整机方案、现有库存等 |
| [平板](./平板/README.md) | 平板 / 二合一；**多轮需求**分文件夹，定案后 [归档](./平板/归档/) 保留对比 |

## 后续可扩展（需要时新建同级文件夹即可）

- **笔记本**：轻薄本 / 游戏本 / 创作本
- **手机 / 穿戴**：与平板生态联动时可单独建目录
- **NAS / 路由 / 智能家居**：偏「设备 + 方案」而非配件拆件

## 通用习惯（各分类通用）

1. 表格**追加行**，不必改表头。
2. **状态**：`调研中` / `候选` / `已定` / `淘汰`。
3. 价格注明**币种、是否含税、采集日期**。
4. 跨分类决策（例如平板配台式机远程办公）可在对应目录 README 里写「关联文档」链接。
