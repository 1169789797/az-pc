# CPU（处理器）

> **升级决策**（性能 + 换主板/内存花费）：见 **[14-CPU升级与换平台对比.md](./14-CPU升级与换平台对比.md)**。

## 选型要点

- **用途**：办公 / 游戏 / 创作（渲染、剪辑）/ 开发编译
- **平台**：Intel（LGA1700/1851 等） vs AMD（AM4/AM5）
- **内存平台**：DDR4 / DDR5（见 [00-平台-DDR4与DDR5.md](./00-平台-DDR4与DDR5.md)）
- **核心数、频率、缓存、TDP、是否带核显**
- 与主板芯片组、内存类型（DDR4/DDR5）绑定

## 笔记

- **12600KF + 精粤 DDR4**：内存 **金士顿 2133 8G×2**（约 2016 旧条）。
- **12600K + 七彩虹 DDR5**：原 **光威龙武** 条 **已售**；整机关 **收起闲置**。
- KF / 5950X / 2600X 均无核显；**12600K** 可 UHD 770 亮机。
- 全套库存与配对见 [13-现有硬件库存.md](./13-现有硬件库存.md)。
