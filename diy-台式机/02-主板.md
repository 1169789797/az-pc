# 主板

## 选型要点

- **芯片组**（如 B760 / Z790 / B650 / X670）与 CPU 匹配
- **内存**：DDR4 还是 DDR5、最大频率、插槽数
- **扩展**：PCIe 版本与槽位、M.2 数量、SATA、USB、网卡/Wi-Fi、音频
- **版型**：ATX / M-ATX / ITX（与机箱兼容）
- **BIOS**：是否已刷支持目标 CPU（尤其新 U 配老板）
