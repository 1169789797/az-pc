# 内存（RAM）

## DDR4 vs DDR5：差距大概多少？

结论先说：**同容量、同代 CPU 下，多数日常和游戏场景 DDR5 只快一截「带宽」，体感往往是几个百分点，不是翻倍**；**钱主要差在主板+内存总价**，要算整机账。详细见下表。

### 1. 纸面规格（双通道，理论带宽量级）

| 常见档位 | 类型 | 理论带宽（约） | 相对 DDR4-3200 | 说明 |
|----------|------|----------------|----------------|------|
| 3200 CL16 | DDR4 | ~51 GB/s | 100% | Intel DDR4 **甜点常见档** |
| 3600 CL18 | DDR4 | ~58 GB/s | ~113% | 再超频收益递减 |
| 5200 CL40 | DDR5 | ~83 GB/s | ~163% | DDR5 入门频率 |
| 6000 CL30–36 | DDR5 | ~96 GB/s | ~188% | **Intel 12/13 代常见推荐档** |
| 6400+ | DDR5 | 更高 | — | 需主板/CPU 体质，不稳定则不如 6000 |

> 带宽公式（简化）：`MT/s × 8 字节 × 2 通道 / 10^9`。  
> DDR5 **单条默认双通道位宽仍是 64-bit×2**，优势主要来自更高 **MT/s**，不是「DDR5 魔法」。

### 2. 延迟（为什么 DDR5 带宽高了，游戏却不一定飞）

| | DDR4 | DDR5 |
|---|------|------|
| 典型 CL | 16–18（3200–3600） | 30–40（5200–6000） |
| 绝对延迟（约） | ~10 ns 量级 | ~10–12 ns 量级（好条可接近 DDR4） |

同样 **~10 ns 延迟** 时，DDR5 靠更高频率拉带宽；**游戏更吃延迟 + 容量 + 双通道**，所以**高带宽不一定等于高帧数**。

### 3. 实际性能差距（经验区间，同 CPU、同显卡）

以下为社区评测与整机测试里**常见幅度**（非绝对值；具体游戏/分辨率会变）。

| 场景 | DDR4（3200–3600 32G） vs DDR5（6000 32G） | 一句话 |
|------|-------------------------------------------|--------|
| **3A 游戏 2K/4K 高画质** | 平均帧 **≈ 0%～5%** | 显卡瓶颈，内存很难拉开 |
| **竞技类 1080p 低画质 / 高帧** | 平均 **≈ 3%～10%**；1% Low 有时多几帧 | CPU 瓶颈时 DDR5 略好 |
| **核显输出** | DDR5 可 **明显更好**（带宽喂核显） | 你 **12600KF 无核显**，此项不适用 |
| **编译、压缩、部分生产力** | **≈ 5%～15%**（看是否内存带宽敏感） | 5950X 大项目仍更看 **容量与通道** |
| **办公、浏览器、多开** | 几乎无差 | **32G vs 16G** 比 D4/D5 重要 |

**配 i5-12600KF 的典型结论**：  
- 独显游戏为主 → **DDR4 3600 32G 双通道** 与 **DDR5 6000 32G** 多数时候 **帧数差距小到可忽略**，不如把钱给显卡/电源。  
- 若已选 **DDR5 主板** → 优先 **6000 附近** 稳定条，不必盲目 7200+。

### 5. 结合你当前库存怎么选

| 你的情况 | 建议 |
|----------|------|
| 精粤 / 七彩虹 B760 **确认是 DDR4 版** | 买 **DDR4 3200 或 3600 32G 套条**，不必再上 D5 |
| 主板是 **DDR5 版** | 买 **DDR5 6000（CL 适中）32G**，BIOS 开 XMP/EXPO |
| 5950X / 2600X + X570、B450 | **仅 DDR4**；5950X 建议 **32G+**，3600 常见 |
| 多套机器混用条子 | **DDR4 条可在 AM4 与 Intel D4 板间复用**（同规格）；**DDR5 不能给 AM4 用** |

## 选型要点

- **类型**：DDR4 / DDR5（由主板与 CPU 决定）
- **容量**：16G（入门）/ 32G（游戏与创作推荐）/ 64G+
- **频率与时序**：如 DDR5 6000 CL30（AMD 常见甜点需查主板 QVL）
- **条数**：双通道优先（2×16G 优于 1×32G）
- **高度**：超高马甲可能影响部分塔式散热器

## 笔记

- 实机录入：2025-10-21；与 [13-现有硬件库存.md](./13-现有硬件库存.md#内存--按整机分配已有) 同步。
