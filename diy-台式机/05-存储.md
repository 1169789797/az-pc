# 存储（SSD / HDD）

## 选型要点

- **系统盘**：建议 NVMe PCIe 4.0（容量 1TB 起常见）；**250G/120G 仅适合轻量系统或老机器**
- **仓库盘**：大容量 SATA SSD 或 HDD（冷数据、游戏库、备份）
- **缓外速度**、TBW 保修、是否有 DRAM 缓存（入门盘需看清）
- **M.2 接口**与主板通道（Gen4 x4 等；多 M.2 时部分 SATA 口可能禁用，看主板手册）

## 备用盘：1T SATA 固态（额外一块）

| 项目 | 内容 |
|------|------|
| 容量 / 接口 | **1T，SATA** |
| 当前状态 | **未绑死某台**，可给任一有空 **SATA 口 + 仓位** 的平台 |
| 「限制的」含义（待你确认） | 可能指：**闲置** spare / 或 **SATA 带宽上限**（比 M.2 慢但仍远快于机械）/ 或 **入门盘**（无 DRAM、QLC 等，当仓库盘仍够用） |
| 品牌型号 | 待补 |

### 推荐指派（优先级可调）

| 推荐 | 平台 | 建议用法 | 效果 |
|------|------|----------|------|
| ★★★ | **Intel-A 12600KF** | **250G SATA 系统** + **本盘 1T SATA → 游戏/Steam** + **1T 机械 → 电影/冷数据** | 主游戏机加载明显好于纯机械 |
| ★★☆ | **AMD-低 2600X** | **120G M.2 系统** + **本盘 1T → 软件/游戏** + 机械作备份 | 减轻小 C 盘压力 |
| ★★☆ | **AMD-高 5950X** | 替换或补充 **1T 游戏机械** → 本盘作 **游戏库** | 5950X 已有多 M.2，SATA 游戏盘也合理 |
| ★☆☆ | **Intel-B 12600K** | 已有 **1T M.2**，再加本盘 **第二 SATA 数据盘** | 非必须，除非 M.2 槽已满要扩容 |

> **玩嘉绝尘**：SSD×2、HDD×2 仓位；12600KF 若 **250G + 1T SATA SSD + 1T HDD** 共 3 块，需核对 **精粤 B760M SATA 口数量** 与机箱 2.5 位安装方式。

## 容量与体验提示

| 容量 | 说明 |
|------|------|
| **120～250G 系统盘** | Win11 + 常用软件后剩余有限；**游戏、Steam 库放机械或大容量 M.2** |
| **1T 单 M.2（12600K）** | 日常够用；大型游戏多时可再加 SATA 盘 |
| **5950X 多盘** | C 小盘 + D 大 M.2 合理；**4T 备份盘**建议与重要数据同步/冷备份分开规划 |
