# 电源（PSU）

## 选型要点

- **额定功率**：CPU+GPU 峰值 + 余量（一般 650W–850W 中端游戏常见）
- **认证**：80 Plus 金牌及以上较常见
- **模组**：全模组 / 半模组便于理线
- **接口**：12VHPWR / 原生 PCIe 5.0 线材（新显卡）
- **质保与品牌口碑**（避免杂牌；**三线/白牌** 750W 标称≠稳定输出）

### 与当前显卡搭配 — 余量判断

| 平台 | 典型负载（粗算） | 现有 PSU | 结论 |
|------|------------------|----------|------|
| **12600KF + RTX 5070** | CPU ~125W + GPU **~200–250W+** + 其他 ~60W → 峰值常 **400W+** | **500W 鑫谷** | ⚠ **5070 长期满载建议 650W+**；核对 **12V 单路瓦数、PCIe 供电针数**；不稳则 **换电源** |
| **12600K**（若复活） | 低 | **750W 杂牌**（闲置套内） | 需先 **补 DDR5 内存**；杂牌质量仍需谨慎 |
| **5950X + 5700 XT** | ~105 + ~225 + ~60 | **650W 振华** | ✓ 常见搭配 |
| **2600X + RX 580** | ~95 + ~185 + ~50 | **500W 振华战斗** | ✓ 副机合理 |
