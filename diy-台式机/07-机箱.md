# 机箱

## 选型要点

- **版型支持**：ATX / M-ATX / ITX（你现有 **B760M / B450M = M-ATX**；**X570 刀锋 = ATX**，不能塞进 M-ATX 机箱）
- **显卡限长**、**散热器限高**、冷排支持（240/360）
- **风道**：前面板进风、网孔面板、风扇位数量
- **静音 / 外观 / 桌下体积**

## M-ATX 性价比锚点 — 玩嘉 绝尘

| 项目 | 内容 |
|------|------|
| 型号 | **玩嘉 绝尘**（侧开磁吸外壳 / 带 DIY 主题） |
| 参考价 | **139 元**（采集 2025-10-21） |
| 版型 | **M-ATX**（兼 ITX） |
| 结论 | 当前调研：**M-ATX 性价比首选候选** |

### 官方/实物规格（已确认）

| 规格 | 数值 |
|------|------|
| **外形尺寸** | **365 × 210 × 422 mm**（长×宽×高） |
| **显卡限长** | **≤ 300 mm** |
| **CPU 散热限高** | **≤ 160 mm** |
| **风扇位** | **120 mm**：**前 ×3**、**上 ×2**、**下 ×2**、**后 ×1** |
| **存储仓位** | **SSD ×2**、**HDD ×2** |
| 特点 | 侧透、侧开磁吸、DIY 主题面板（以实际 SKU 为准） |

> 顶 **2×120** 常与 **240 水冷** 冷排位共用（装冷排则占顶扇位，以说明书为准）。

### 139 元档简评

| 优点 | 注意 |
|------|------|
| 价格低，配 **精粤 / 七彩虹 B760M**、**B450M** 合适 | **限长仅 300 mm**，比很多 M-ATX（330 mm）更紧 |
| 7 个 120 风扇位，风道可玩 | **RTX 5070 大地之神** 很可能超长 → **必须先量卡长** |
| SSD/HDD 各 2 位，存储灵活 | 5700 XT 三风扇版多数 ≤300 mm，仍建议实测 |
| 侧开磁吸、DIY 主题 | 160 mm 内塔散；超高双塔需核对型号 |
