# 显示器与外设（可选）

## 显示器选型要点

- **分辨率 + 刷新率**（1080p 144 / 2K 165+ / 4K 60）
- **面板**：IPS / VA / OLED；响应时间、色域（创作需关注）
- 与显卡输出接口（HDMI 2.1 / DP）

## 键盘选型要点

- **连接**：有线（无续航焦虑）/ 2.4G / 蓝牙
- **轴体**：红轴（线性、轻、游戏常见）、茶轴（段落感）、青轴（有声段落）等
- **配列**：108 键全尺寸 / 87 TKL / 75% / 68 等
- **键帽与背光**：PBT 更耐磨；单色/ RGB 看需求
- **办公 vs 游戏**：红轴长时间打字也常见，青轴注意噪音
