## 电源选购原则（必看）

电源是整机里**最不值得省钱**的件之一：虚标、杂牌、老电容可能导致 **蓝屏、重启、烧显卡**，换电源的成本往往低于修硬件。

### 三条硬标准（你定的底线）

| 标准 | 要求 | 说明 |
|------|------|------|
| **80 Plus 认证** | **至少铜牌（Bronze）及以上** | 白牌/无认证直接排除；**铜牌 ≤ 银牌 ≤ 金牌 ≤ 白金 ≤ 钛金**。游戏/独显主机更建议 **金牌** 起步（效率与用料通常更好，价差常值得） |
| **质保** | **尽量长** | 一线/靠谱型号常见 **5～10 年**；**3 年以下**要警惕。买前看 **只换不修 / 上门** 等条款与 **是否全国联保** |
| **电容与方案** | **电容要好** | 优先宣传 **全日系电容**（或主电容日系）的型号；方案上 **LLC + DC-DC** 比老旧的 **双管正激 + 磁放大** 更常见在中高端。商品页若只写「静音」「炫彩」不写电容与方案，降级考虑 |

### 选购 checklist（下单前勾一遍）

- [ ] **80 Plus ≥ 铜牌**（独显游戏机建议 **≥ 金牌**）
- [ ] **额定功率**按 CPU+GPU 峰值留 **20%～30% 余量**（见 [06-电源.md](./06-电源.md)）
- [ ] **+12V 单路/联合输出** 瓦数够（铭牌上看 **+12V × A**）
- [ ] **PCIe 显卡供电线** 数量、接口（8pin / 12V-2×6）匹配显卡
- [ ] **模组**：全模组 / 半模组 便于小机箱理线（非必须，但体验好）
- [ ] **质保年限** 与 **换新政策** 已确认
- [ ] 避开 **无名「750W 白牌模组」** 仅看瓦数不看品牌的套路

### 认证与质保（参考，非绝对）

| 等级 | 典型定位 | 备注 |
|------|----------|------|
| 铜牌 | 入门合规 | **符合你「铜牌以上」底线**；低端独显、办公可以 |
| 银牌 | 中间档 | 市场上相对少，同价常直接看金牌 |
| **金牌** | **游戏主机甜点** | 效率、温升、用料平衡；**12600KF + 中高端显卡** 建议从此档选 |
| 白金 / 钛金 | 高端、大瓦数 | 价高；高瓦数 + 长期满载可考虑 |

| 质保（常见印象） | 说明 |
|------------------|------|
| **7～10 年** | 海韵、振华部分型号、高端安钛克/酷冷等 |
| **5 年** | 不少金牌中端型号 |
| **3 年** | 入门；仅当价格极好且功率需求低时再考虑 |

### 电容 / 用料（商品页关键词）

| 优先 | 谨慎 |
|------|------|
| 全日系电容、日系主电容 | 只写「高品质电容」不写产地 |
| LLC 谐振 + DC-DC 12V | 极低价大瓦数、无方案说明 |
| 过压 / 过流 / 短路 / 欠压保护写全 | 无 3C、无 80Plus 可查编号 |
