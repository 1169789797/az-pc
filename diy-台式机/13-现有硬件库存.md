## 可组成的「整机平台」思路

你手头其实是 **2～3 套平台** 的料（内存/显卡/电源等另配）：

| 平台代号 | CPU + 主板 | 定位（待你定用途） | 还缺什么（常见） |
|----------|------------|--------------------|------------------|
| **Intel-A** | 12600KF + 精粤 B760M | **老家 · 节假日** | 鑫谷 500W；平时闲置 |
| **Intel-B** | 12600K + 七彩虹 B760M | **收起闲置** | **无内存**；杂牌 750W 等在箱；恢复需买 **DDR5** |
| **AMD-高** | 5950X + X570 刀锋 | **租房 · 日常主力** | GX650；2K144 |
| **AMD-低** | 2600X + B450M DSH | **老家 · 节假**（**~2022 起**） | 战斗版 500W；580 + 1080p |

> 两台 Intel 为 **不同时间、不同机箱** 的整机，勿随意对调主板/内存/显卡。

## 装机前待确认 checklist

- [x] B760M：**精粤 = DDR4**、**七彩虹 = DDR5**（已按实机内存确认）
- [ ] 12600KF：**2133 16G** 是否稳定双通道；长期是否升级 **32G DDR4**（2600X/5950X 的 DDR4 条**不可**给 KF 机混用不同套条时需留意）
- [ ] **Intel-B 若复活**：重买 **DDR5 2×16G**（七彩虹 B760M）；龙武条 **已售** 不再适用
- [ ] **B450M** BIOS 版本（2600X 如需）
- [ ] **老家 12600KF**：回村长玩前再查 **GP600G + 显卡**（5070 偏紧 / 5700 XT 较稳）；**平时不用可不做优先升级**
- [ ] **租房 5950X 主力机**：硬盘备份、电源/显卡稳定性 **优先于** 老家机折腾
- [ ] **5700 XT 讯景** 卡长 vs 机箱（M-ATX 机箱尤其注意）
- [ ] **5950X** 四盘线材与 SATA 口数量（X570 刀锋一般够用，确认 M.2 与 SATA 是否共用通道）
- [ ] **12600KF** 精粤 B760M：**SATA 固态 + 机械**  SATA 线/供电位
