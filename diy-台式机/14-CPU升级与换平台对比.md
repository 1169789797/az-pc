# CPU 升级与换平台对比

把 **现有 CPU** 和 **想换的目标 CPU** 放在一起比：**性能** + **要花多少钱**（含是否必须换主板、内存）。  
实机绑定见 [13-现有硬件库存.md](./13-现有硬件库存.md)。

## 2. 换 CPU 要动哪些件？（平台规则）

| 升级类型 | 条件 | 通常还要买 | 旧件处理 |
|----------|------|------------|----------|
| **A. 只换 CPU** | 新 U **同插槽** + 主板 BIOS 支持 | 无（或散热扣具） | 旧 U 可出二手 |
| **B. 换 CPU + 主板** | 插槽或芯片组变了 | **主板** | 旧板+旧 U 可成套出 |
| **C. 换 CPU + 主板 + 内存** | 内存世代变了（**DDR4↔DDR5**、AM4→**AM5** 等） | **主板 + 内存**（常建议 32G） | DDR4/板子整出 |
| **D. 整平台换** | 机箱/电源/散热不兼容 | 可能 **机箱、电源、散热** | 见 [06-电源](./06-电源.md)、[07-机箱](./07-机箱.md) |

### 你现有四套平台的「换 U 边界」

| 当前平台 | 同板可升级方向（调研时自行填具体型号） | 跨平台方向 |
|----------|----------------------------------------|------------|
| **LGA1700 + 精粤 DDR4**（12600KF） | 同插槽 12/13/14 代（如 i5-13400F、i5-13600KF 等，**BIOS 需支持**） | 换 **LGA1851/15 代** → **B. 或 C.** |
| **LGA1700 + 七彩虹 DDR5**（12600K 闲置） | 同板 12/13/14 代 **DDR5** | 同上 |
| **AM4 + X570**（5950X） | **5950X 已顶格**；可换 **5800X3D** 等（游戏向，多核降） | → **AM5** = **C. 全套 D4 内存不能沿用** |
| **AM4 + B450**（2600X） | 可 BIOS 刷到 **5600 / 5700X** 等（看供电，**不推荐 5950X**） | → AM5 / Intel 新平台 = **换整机平台** |

## 4. 成本对比（核心）

### 4.1 公式

```text
升级净成本 ≈ 新 CPU 价 + 新主板价 + 新内存价 + 散热/电源差价 − 旧 CPU 二手价 − 旧主板二手价 − 旧内存二手价
```

只换 U（类型 A）：

```text
净成本 ≈ 新 U 价 − 旧 U 二手价
```

| 方案名 | 目标 CPU | 主板 | 内存 | CPU(元) | 板(元) | 内存(元) | 其它 | **合计** | 可回收(元) | **净成本** | 类型 |

| 5950X→（同 AM4 U） | 例 5800X3D | **沿用 X570** | 沿用 | | 0 | 0 | | | 出 5950X | | **A** |

| 12600KF→同板 | 例 13600KF | **沿用精粤 D4** | 沿用/升D4 | | 0 | 可选 | | | 出 12600KF | | **A** |

### 4.3 同钱花哪台更值（决策辅助）

| 净预算(元) | 更可能划算的方向 | 原因（结合你的使用） |
|------------|------------------|----------------------|
| &lt;500 | **2600X→5600** 或 **补 12600K 的 DDR5 条** | 小改或复活闲置 |
| 500～1500 | **12600KF 同板换 13/14 代** 或 **5800X3D 换 5950X**（游戏） | 类型 A，不动内存 |
| 1500～3500 | **AM5 入门 U + B650 + DDR5**（若出 5950X 平台） | 类型 C，**租房主力**才值得 |
| &gt;3500 | 新平台 + 可能显示器/电源 | 与 [10-整机方案对比](./10-整机方案对比.md) 联动 |

### 5.3 老家 — 2600X + B450M DSH

| 项目 | 内容 |
|------|------|
| 现状 | 2019 平台；节假轻量；**技嘉 B450M DSH** |
| **类型 A 上限** | **R5 5600** / 5600X / 5700X 等（**BIOS + 供电**） |
| 性价比 | 通常 **小预算换 U** 即可，**不换 AM5** 除非弃机 |

#### 2600X → 5600：要不要换更强主板？

**结论：一般不用。** 5600 仍属 **AM4**，**B450M DSH 在刷好 BIOS 后可直接换 U**，属于 **类型 A（只换 CPU）**。

| 对比项 | 2600X | R5 5600 | 对 B450M 的影响 |
|--------|-------|---------|-----------------|
| 架构 | Zen+ | Zen 3 | 需 **BIOS 支持 5600**（技嘉官网查 DSH 最新 BIOS 说明） |
| 标称 TDP | 95W | **65W** | 5600 **不比 2600X 更吃供电**；M-ATX 板 **默频/小超** 通常够 |
| 内存 | DDR4 | DDR4 | **光威 8G×2 可继续用**（建议双通道插法不变） |

**必须做的：**

1. 上技嘉官网确认 **B450M DSH** 的 BIOS 是否支持 **Ryzen 5000（Vermeer）**；不支持则 **先刷 BIOS**（有时需用 2600X 刷完再换 5600）。
2. 换 U 后进 BIOS：**PBO 可先关**，稳定再试；副机 **不必强上 X570**。

**不必换主板，除非：**

- 想要 **更多 M.2 / USB / 更好扩展**（不是 5600 刚需）；
- 计划以后上 **5950X 级** 长期满载（你已有 **5950X+X570** 干这个，**2600X 机不必**）；
- 当前板 **BIOS 永远不支持 5000 系**（极少见，先查官网）。

**成本粗算（未来两年计划）：**

| 项目 | 金额(元) |
|------|----------|
| R5 5600 盒装/散片 | 待查（促销常 600～800 档波动） |
| 新主板 | **0**（沿用 B450M DSH） |
| 内存 | **0**（沿用 DDR4；可选以后升 32G） |
| 旧 2600X 出手 | − 待填 |
| **净成本** | ≈ 5600 价 − 二手 2600X |

**本机对比记录：**

| 目标 CPU | 净成本 | 决定 |
|----------|--------|------|
| **R5 5600** | 待填 | **同板升级，不换主板** |

### 5.4 闲置 — 12600K + 七彩虹 DDR5

| 项目 | 内容 |
|------|------|
| 现状 | **无内存**；整机关 |
| 选项 1 | **买 DDR5 32G** 复活 — 净成本 ≈ 内存价 |
| 选项 2 | **出 CPU+板+电源+机箱**；不再升级 |
| 选项 3 | 同板 **换 U** 无意义（除非先复活） |
