## 使用建议

1. 在各分类文件中往表格**追加行**即可，不必删表头。
2. **状态**列：`调研中` / `候选` / `已定` / `淘汰`。
3. **性价比**可用 1–5 星，或写简短结论（如「同价位游戏首选」）。
4. 价格建议注明**币种、是否含税、采集日期**（行情波动大）。
5. CPU + 主板务必核对：**插槽、芯片组、BIOS 是否支持该 CPU**。
