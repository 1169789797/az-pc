# 平板设备调研

用于对比 **Android / iPadOS / Windows 平板 / 二合一**。支持**多轮、互不覆盖**的选购：每一轮需求单独文件夹，定案后归档保留。

← [返回总目录](../README.md)

## 怎么用（多轮需求）

```text
平板/
├── 索引.md          ← 所有轮次一览（进行中 / 已定 / 搁置）
├── _模板/           ← 复制此文件夹开新轮，勿在此填真机
├── 进行中/          ← 当前在比的每一轮一个子文件夹
└── 归档/            ← 定案或搁置后整包移入，对比表原样保留
```

1. 打开 **[索引.md](./索引.md)**，看已有轮次。
2. 新需求：复制 `_模板` → `进行中/YYYYMMDD-简述`，填 `需求.md` → `对比.md`，在索引加一行。
3. 买定或暂不买了：写该轮 `结论.md`，文件夹移到 `归档/`，更新索引状态。

## 单轮文件夹内文件

| 文件 | 说明 |
|------|------|
| `需求.md` | 场景、约束、权重（本轮独有） |
| `对比.md` | 候选机型表（本轮独有，归档后作历史） |
| `结论.md` | 定案快照（归档前填写） |

## 其他习惯

- 对比表必列 **上市/发售**（国内首销年月）；商品「2025款」等于 2024 开售的，在备注写清，方便判断是否快换代。
- **不马上买**：每轮 `对比.md` 维护「代际提醒」— 哪些已发售超过一年、同系列下一代大概何时值得关注。
- 对比表里机型 **状态**：`调研中` / `候选` / `已定` / `淘汰`。
- 笔、键盘、扩展坞建议单独列或写在备注。
- 与台式机分工可链到 [diy-台式机](../diy-台式机/README.md)。
- 对比表里写 **骁龙 / 天玑** 时，可链 [芯片分级与火龙冰龙](../芯片与SoC/01-手机平板CPU分级对比.md)。
