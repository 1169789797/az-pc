# 【定案后填写】结论快照

整轮进入 [归档](../归档/) 前填写本页，便于以后只看结论、不回翻整张对比表。

| 项 | 内容 |
|----|------|
| 定案日期 | |
| 整轮状态 | 已定 / 搁置 / 淘汰 |
| 最终选择 | 品牌型号、配置（存储、是否蜂窝等） |
| 实际成交 | 金额、渠道、日期 |
| 主要理由 | 2–3 条（可对照 [需求.md](./需求.md) 权重） |
| 未选机型 | 各写一句淘汰原因即可 |
| 配件 | 笔、键盘、膜套等 |
| 备注 | 保修、二手、后续是否还会二轮升级 |

详细参数对比仍保留在同文件夹的 [对比.md](./对比.md)，**不要删**。
