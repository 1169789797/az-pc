## 1. 主用途（已确认）

- [x] **长时看视频**（单日常见：**9:00–13:00**、**17:00–21:00**，合计可达 **约 8h**）
- [x] **抖音**等竖屏/短视频
- [x] **小说 / 阅读类 App**
- [x] 游戏：**频率很低**，约 **一周 ≤8 小时**（轻度或可不装大型游戏）
- [ ] 手写、办公、蜂窝出门 — **非主需求**（蜂窝见对比表 4G 行）

## 2. 硬约束

| 项 | 要求 |
|----|------|
| **屏幕尺寸** | **严格小于 12 英寸**（**不含 12 寸**）；越大越上限 11.x，倾向 **9–11"** 随身看片 |
| **价格（硬上限）** | **全新到手 ≤ ¥2000**；**二手 ≤ ¥1300**（含配件整包也按整机价算） |
| 存储 | **128G** 可接受；视频可缓存 + **TF 卡**更省心 |
| 性能 | 影音 + 信息流足够即可，**不追 8 Gen 3 / 165Hz 电竞** |

## 3. 与现有设备的关系

| 已有设备 | 希望平板承担什么 | 备注 |
|----------|------------------|------|
| 台式机（见 [diy-台式机](../../../diy-台式机/13-现有硬件库存.md)） | 大屏重活仍靠 PC | 平板 = **沙发/ bed 长时刷内容** |
| 手机 | 抖音/小说若手机太小眼累，用平板替 | 同小米生态可选 Redmi |

## 4. 决策权重（1–5）

| 维度 | 权重 | 说明 |
|------|------|------|
| **价格 / 性价比** | **5** | 不看游戏性能则 Y700 溢价大 |
| **长时看片舒适度** | **5** | 护眼认证、DC 调光、亮度、扬声器 |
| **续航** | **4** | 一天两段长时间使用，最好少插电；可接受边充边看 |
| **尺寸 & 重量** | **4** | **&lt;12"**；在合规范围内 **略大比过小更利于看剧**（9.7" vs 8.8"） |
| **性能 / 游戏** | **1** | 每周 ≤8h 游戏，6s Gen 2 够用 |
| 扩展（TF 卡） | **3** | 缓存剧集、小说离线 |
| 生态 | **2** | 非决定性 |
