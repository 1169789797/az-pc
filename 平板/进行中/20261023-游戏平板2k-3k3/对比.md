## 游戏向简评（针对你点名的几款）

| 游戏 | 说明 | 对硬件 |
|------|------|--------|
| **原神 / 鸣潮 / 星铁 / 绝区零** | 开放世界/3D，吃 GPU 与散热 | **8 Gen 3 + 12G** 更稳；建议 **中-高画质** 预期，别强求手机同款「最高」 |
| **逆战 M** | 射击、帧率与触控 | **165Hz 屏 + 散热** → 更偏 **Y700** 或 GT2 的高刷调校 |
| **明日方舟** | 2D/策略 | 性能压力小 |

## 怎么二选一（荣耀 GT2 Pro vs Y700 2025）

| 选 **荣耀 GT2 Pro** | 选 **Y700 2025** |
|---------------------|------------------|
| 屏幕 **12.5"** 沉浸、看技能范围 | **8.8"** 轻、躺玩/handheld 感 |
| **10100mAh**，连玩几小时 | **双 X 轴马达**、电竞调校、**双 USB-C** |
| 原神/星铁等 **大屏 + 散热系统** | 逆战 M 类 **射击手感** 更贴「游戏平板」定位 |
| 接受 **&gt;12 寸**、约 **500g+** 级重量 | 接受 **6550mAh**、游戏久要 **插电/旁路充** |
