> 采集 / 整理：**2026-10-23** · 口径：**中国大陆常见安卓 + 苹果** 移动 SoC（非 x86 笔记本、非 DIY 桌面 CPU）。

## 1. 先读懂几个词

| 术语 | 含义 |
|------|------|
| **峰值性能** | 跑分、短 burst、游戏刚开前几分钟的帧率 |
| **持续表现** | 长时间游戏 / 录屏 / 导航后是否 **降频、掉帧、烫手**（平板通常 **优于同芯片手机**） |
| **火龙** | 社区戏称：**易发热、降频猛、体验不稳定** 的 SoC 或某代制程/调度组合（**不是官方分类**） |
| **冰龙** | 社区戏称：**同档里更凉、更稳、长期性能保留好**（同样非官方） |
| **8 Gen 3 / 8s Gen 3** | 名字相近，**8s 明显低一档**，买平板/手机时别混 |

**怎么用本文**：先定用途（刷剧 / 原神类 3D / 射击高帧）→ 找 **分级** → 看 **持续表现 + 火龙/冰龙印象** → 再回到具体机型对比 **散热堆料**（游戏平板 VC、面积）。

### 4.1 「联发科 U100」？—— 先分清名字

| 情况 | 说明 |
|------|------|
| **联发科官方移动 SoC 列表里，没有叫「U100」的芯片** | 常见是 **天玑 6300/7300/8200…** 或旧平板芯 **MT8163 / MT8788** 等 |
| 商品写 **「U100 八核」** | 多为 **整机代号 / 卖家自造名**，真实芯片可能是 **MT6737、SC9863、展锐 T610/T615** 等 **老四核 A53**，甚至 [跑分软件才能看真型号](https://probiv.work/threads/kogda-obmanuli-vo-vsem-izuchaem-fejkovyj-planshet-kotorym-zabity-marketplejsy.163598/) |
| **U100 = 某款平板/工控型号** | 例如工业 **Gutab U100** 是 **Intel 奔腾 N6415**（Windows），**不是联发科** |
| 是否口误 **6300**？ | **天玑 6300** 是正规 **入门 5G 芯**，比下面「老杂牌芯」**强一个时代**，能刷剧，仍 **不适合** 原神/鸣潮高画质 |

**「类似 U100 宣传」的老/入门芯，算不算很差？**

| 真实档次 | 例子 | 相对今天 | 对你用途 |
|----------|------|----------|----------|
| **正规入门（2023+）** | 天玑 **6300/7300**、骁龙 **6s Gen 2** | 不「差」，是 **刻意低配省钱** | 刷剧/抖音/小说 ✓；3D 主力 ✗ |
| **老平板 / 白牌常用** | **MT6737、MT8167**、展锐 **T610/T615**、RK3326 | **性能明显落后**；不一定烫（**弱+老**，不是经典火龙） | 轻量 App 尚可；**易卡、系统旧**；3D 痛苦 |
| **虚标机** | 标 16G+512G +「U100」 | **可能连芯片型号都假** | **不建议买** |

结论：**不是「联发科 U100 都很差」**——因为 **往往根本没有这颗 U**；若是 **6300/7300 这类**，属于 **入门能用**；若是 **老 A53 / 白牌虚标**，对 **2026 年标准** 算 **很差**，且和 **Redmi Pad 2 SE（6s Gen 2）** 不是一档。

**到手后建议**：装 **DevCheck / CPU-X** 看 **SoC 真实型号**，再对照本文 §2 分级。

## 6. 平板 vs 手机：同芯片为何不一样

| 因素 | 手机 | 平板（尤其游戏平板） |
|------|------|----------------------|
| 散热面积 | 小，易 **3～5 分钟** 降频 | **VC 面积常更大**（如 Y700、GT2） |
| 电池 | 触发温控更 aggressive | 可 **旁路供电 / 充电分离** 边玩边充 |
| 你的场景 | — | **长时看片** → **6s Gen 2 即可**（[影音轮](../平板/进行中/20261023-Redmi与Y700/对比.md)） |
| 你的场景 | — | **原神/鸣潮等** → **8 Gen 3 档** 更合理（[游戏轮](../平板/进行中/20261023-游戏平板2k-3k3/对比.md)） |

## 8. 选购口诀（手机 / 平板通用）

1. **只刷剧**：入门 **6 系** 够；别为 8 Gen 3 加钱。  
2. **多款 3D 手游常驻**：至少 **8 Gen 2 / 8 Gen 3 / 天玑 9300+** 档；优先 **游戏平板散热规格** 而非只看芯片名。  
3. **看到「8s」**：默认比 **8 Gen 3** 低一档，持续输出差距 **大于** 跑分差距。  
4. **怕火龙**：避开 **888、8 Gen 1** 二手；同代优先 **台积电改版（8+）** 或 **8 Gen 2 及以后**。  
5. **不马上买**：新 SoC 发布后 **12～18 个月** 同档降价；见各轮 [对比.md 代际提醒](../平板/进行中/20261023-游戏平板2k-3k3/对比.md)。  
6. **看到 U100 / 十核 / 16G 千元机**：先默认 **高风险虚标**，查真 SoC 再下单（见 **§4.1**）。
