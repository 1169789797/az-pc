## 维护习惯

1. 新 SoC 发布：**追加行**，旧代标「上一档」而非删历史（方便看代际）。
2. **火龙/冰龙** 是社区口语，随 **机型散热、系统调度、环境温度** 会变—以「典型印象 + 例外备注」写。
3. 平板与手机 **同芯片** 时，平板往往 **持续输出更好**（更大机身、散热面积），表中单独注明。
